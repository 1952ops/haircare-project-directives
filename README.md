# HAIRCARE Project Directives

This repository stores portable project-structure directives for the HAIRCARE workflow.

Start with:

- `0000-LLM-PROJECT-DIRECTIVES.md` for naming rules future LLMs should follow.
- `HAIRCARE-000T-Project-System-Debrief.md` for the debrief of why the model project worked.
- `project_sources/` if attached evidence snapshots are later committed or mirrored.

The key convention is:

```text
0000 — START HERE — PROJECT CHARTER
0001 — LIVE ASSESSMENT
0002 — SOURCE LOG
0003 — DECISION FRAMEWORK
0004 — OPEN QUESTIONS
001A — EVIDENCE — FIRST EVIDENCE ITEM
001PS — PROFESSIONAL SOURCE — FIRST PROFESSIONAL SOURCE
001UO — USER OBSERVATION — FIRST USER OBSERVATION
001DX — DISCREPANCY — FIRST DISCREPANCY
001GD — GOVERNANCE DECISION — FIRST GOVERNANCE DECISION
9999 — CHANGELOG
```
